# Vodafone SuperNet Unlim connection monitor

Небольшая Windows-утилита для наблюдения за мобильным интернетом, который телефон раздаёт компьютеру. Изначально сделана для случая Vodafone Ukraine SuperNet Unlim, Xiaomi/Android и Windows. Это независимый диагностический проект, не продукт и не официальная поддержка Vodafone.

Панель показывает задержку до шлюза телефона и внешних узлов, короткие замеры загрузки/отдачи, а при подключённом Android — регистрацию в LTE и доступные показатели радиосигнала. Кнопка **«Графики»** открывает отдельное окно с задержкой, скоростью, RSRP, RSRQ и RSSNR.

При нестабильном соединении окно не выводится поверх других программ: значок приложения мигает на панели задач до восстановления сети.

## Запуск

1. Подключите компьютер к точке доступа телефона.
2. Запустите `start-vodafone-network-monitor.bat` или выполните `python vodafone-network-monitor.py`.
3. Чтобы видеть LTE-параметры, подключите Xiaomi кабелем передачи данных, включите USB debugging и подтвердите запрос отладки. Проверки интернета работают и без ADB, но без радиопараметров телефона.
4. Нажмите **«Графики»**, чтобы открыть графики. По умолчанию они показывают последние 15 минут; можно выбрать 5, 30 или 60 минут либо весь текущий сеанс.

Нужен Python 3 с Tkinter. Внешние Python-пакеты не используются. Если `adb.exe` лежит в соседней папке `platform-tools`, скрипт найдёт его автоматически; сами бинарники Android Platform Tools в репозиторий не включены.

## Журналы и приватность

Каждый запуск создаёт папку `vodafone-monitor-*` с `metrics.csv`, `events.csv` и пояснением. Графики ограничивают только отображаемый временной диапазон; CSV продолжает хранить полный запуск.

Журналы могут содержать точные временные отметки и идентификатор обслуживающей соты. Они исключены из Git через `.gitignore`; перед публикацией не добавляйте их вручную. Папка `platform-tools` тоже исключена.

## Ограничения

- Утилита рассчитана на Windows; интерфейс сейчас на русском.
- Показатели LTE считываются с Android через ADB и зависят от версии Android и прошивки. Для iPhone ADB-радиопоказателей нет, но проверки соединения компьютера через точку доступа остаются доступны.
- Ping может фильтроваться сетью. Результаты небольших HTTPS-передач отражают путь до контрольного сервера и сами по себе не доказывают причину сбоя.
- Это диагностический инструмент для конкретного сценария; в других сетях и конфигурациях пороги и выбор контрольных узлов могут потребовать настройки. Проект можно форкнуть и адаптировать.
