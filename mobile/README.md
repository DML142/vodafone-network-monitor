# Android-приложение

Независимое приложение для диагностики мобильного интернета на Android-телефоне. Проект использует Flutter/Dart для интерфейса и Kotlin для Android-части. ADB для работы приложения не потребуется.

**Сейчас реализован только каркас:** обзор, пустые экраны графиков и сессий, настройки темы и экран пояснения разрешений. Приложение пока не измеряет сеть и не запрашивает разрешения. iOS-реализации здесь нет.

## Сборка

Минимальная версия Android — API 26 (Android 8). Проект создан Flutter 3.47.3; `pubspec.yaml` требует Dart 3.13.3 или новее. Для APK нужен установленный Android SDK и согласованные лицензии Android SDK.

Из этой папки выполните:

```powershell
flutter pub get
flutter run
```

Для debug APK:

```powershell
flutter build apk --debug
```

SDK и устройство нужно настроить локально. APK на физическом телефоне ещё не собран и не проверен.

## Структура

- `lib/app` — запуск приложения, навигация, темы и общие элементы.
- `lib/features` — экраны обзора, графиков, сессий, настроек и диагностики разрешений.
- `android/app` — Android-хост на Kotlin.

Локальные журналы, экспорты, ключи подписи и файлы конфигурации Android SDK не добавляются в Git.
