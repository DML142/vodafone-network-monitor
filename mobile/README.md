# Монитор мобильной сети для Android

Приложение показывает доступность сети и внешнего HTTPS-узла, задержку, доступные радиоданные и графики записи. Данные сессий хранятся локально. Поддерживается Android 8 (API 26) и новее; root и ADB для обычного использования не нужны.

## Возможности

- Запись сетевых проб и доступных радиоданных с постоянным уведомлением и кнопкой остановки.
- Графики задержки, общего уровня сигнала, RSRP, скачивания и отдачи; история сессий и экспорт CSV/JSON.
- Ручной скоростной тест; во время записи можно отдельно включить автоматические тесты и выбрать интервал от 30 секунд.
- Радиоданные читаются только после выдачи Android-разрешения на точное местоположение. Приложение не запрашивает координаты и не сохраняет идентификаторы сот, телефона или SIM.

## Ограничения и трафик

- Android и прошивка могут возвращать CellInfo с задержкой, ограничивать частоту обновления или не предоставлять часть полей. На Xiaomi настройки энергосбережения тоже могут влиять на продолжение записи в фоне.
- GSM не предоставляет RSRP/RSRQ/RSSNR. Для такого подключения приложение показывает доступный общий сигнал в dBm; RSRP относится к LTE/NR.
- Автотест скорости выключен по умолчанию. Каждый тест передаёт до 10 МБ на скачивание и до 10 МБ на отдачу; при интервале 30 секунд верхний предел составляет около 2,4 ГБ за час. Тесты используют `speed.cloudflare.com`; сервер видит IP-адрес соединения.
- Лёгкие HTTPS-пробы обращаются к выбранному контрольному узлу (по умолчанию `connectivitycheck.gstatic.com`).

## Установка

Скачайте Android APK со страницы [релизов GitHub](https://github.com/DML142/vodafone-network-monitor/releases) и откройте файл на телефоне. Для просмотра радиоданных выдайте запрошенное разрешение; без него сетевые пробы и запись продолжают работать.

## Сборка

Из этой папки выполните:

```powershell
flutter pub get
flutter analyze --no-pub
flutter build apk --release
```

APK появится в `build/app/outputs/flutter-apk/app-release.apk`. Для сборки нужны Flutter и Android SDK с принятыми лицензиями.
